
# Robinah Nakabugo | Personal Portfolio

A personal portfolio website highlighting my software development projects, technical skills, and professional experience.

## About the Project

This portfolio brings together my work, skills, and professional background in one place. It allows visitors to explore my projects, learn more about me, and connect with me.

## Features

- Responsive design for desktop and mobile devices.
- Project showcase and technical skills.
- Professional background and downloadable CV.
- Smooth animations and interactive elements.
- Contact information and professional links.

## Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling, layouts, and animations.
- **JavaScript** – Interactive functionality.
- **Netlify** – Website hosting.
